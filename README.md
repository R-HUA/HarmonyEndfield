# HarmonyOS 云·终末地

实验用途的 HarmonyOS 网页宿主。使用[云·终末地官方页面](https://endfield.hypergryph.com/cloud)。本项目不是官方客户端。

支持手机与平板横屏、ArkWeb 页面、网页弹出页、视频全屏、返回处理、前后台恢复和媒体状态诊断。

最低兼容 API 14；支持手机、平板。网页占满窗口，工具默认隐藏；首次返回显示工具及退出提示。系统栏透明叠加，仅随网页真实全屏事件隐藏；回到前台不主动刷新会话。

官方悬浮球收起时贴合屏幕边缘，仅在与实际挖孔重叠时避让挖孔；展开、点击与拖动继续使用官网行为。使用 `EndfieldCloud` 标签输出分级日志。
